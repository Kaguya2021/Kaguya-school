# Public School Helper Telegram Bot

Персональный публичный Telegram-бот для школьников. Выполнен на Python 3.11+, aiogram 3.x, SQLAlchemy 2.x, SQLite и APScheduler.

## Инструкция по локальной установке

### 1. Создание бота в BotFather
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям.
3. Скопируйте полученный **Bot Token**.
4. Узнайте ваш Telegram ID (например, через [@userinfobot](https://t.me/userinfobot)) для прав администратора.

### 2. Настройка проекта
1. Клонируйте репозиторий или скачайте исходный код.
